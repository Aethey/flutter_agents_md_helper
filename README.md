# Flutter AGENTS.md Helper

[![Flutter](https://img.shields.io/badge/Flutter-Web-02569B?logo=flutter&logoColor=white)](https://flutter.dev)
[![Live Demo](https://img.shields.io/badge/GitHub%20Pages-Live-2ea44f?logo=github&logoColor=white)](https://aethey.github.io/flutter_agents_md_helper/)

Turn project requirements into architecture decisions, then export `FLUTTER_ARCHITECTURE.md` for coding agents.

🌐 **[Open live demo](https://aethey.github.io/flutter_agents_md_helper/)**

## Flow

```text
Requirements → Options → Trade-offs → Decisions → FLUTTER_ARCHITECTURE.md
```

## Run locally

```bash
flutter pub get
flutter run -d chrome
```

## Build for GitHub Pages

```bash
flutter build web --release --base-href "/flutter_agents_md_helper/"
```
